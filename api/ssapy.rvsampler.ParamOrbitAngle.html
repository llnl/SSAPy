ParamOrbitAngle

class ssapy.rvsampler.ParamOrbitAngle(initparam, epoch, initObsPos, initObsVel, **kwargs)[source][source]

Bases: ParamOrbitTranslator

Translate between angle-based orbital parameters and orbit objects.

Parameters:

  • initparam (array-like) – Initial orbital parameters.

  • epoch (float or astropy.time.Time) – Epoch time for the orbit.

  • initObsPos (array-like) – Initial observer position vector.

  • initObsVel (array-like) – Initial observer velocity vector.

  • kwargs (dict) – Additional keyword arguments passed to ParamOrbitTranslator.

initObsPos[source]

Initial observer position vector used for angle-based calculations.

Type:

array-like

initObsVel[source]

Initial observer velocity vector used for angle-based calculations.

Type:

array-like

Notes

ssapy.compute.radecRateObsToRV() converts angular parameters to position and velocity vectors. ssapy.compute.rvObsToRaDecRate() converts orbit position and velocity vectors back to angular parameters.
